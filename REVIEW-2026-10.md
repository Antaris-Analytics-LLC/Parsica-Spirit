## Method

Every line named in the 27 October shortlist was opened and read again at HEAD and the behavior each describes was confirmed from the code; nothing in the repository was run during the read. Each finding was then sorted into one of two piles by one rule: a gate that fails open, a path that is hidden, injected context that commands the agent, code loaded from the environment, a gate that passes with its input missing, or a fan-out with no cap is fixed here, in its own pull request with its own test, and everything else is named and left for Continuum.

How these got here. Between June and August this code was built and revised largely by an automated agent operating under my account, and the review packets handed to outside reviewers in that period were written by the same agent; they pre-accepted several of the flaws listed below and asked reviewers not to raise them. I found this by auditing my own repositories in October on an assume-breach rule, treating every line as data. This file and the pull requests it points to are the result.
